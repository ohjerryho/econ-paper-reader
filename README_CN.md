**作者**: ohjerryho  
**版本**: 0.6.0  
**许可证**: MIT

## 这个技能做什么

经济学文献有一套严格的叙事逻辑——每个章节有其职责，每张表格讲述一部分故事，每种识别策略依赖特定的假设。读懂文献，首先要知道每个部分"应该"包含什么。

`econ-paper-reader` 将顶级期刊的写作规范"反转"，从写作惯例倒推阅读框架。结果是：对任意一篇经济学文献的结构化、批判性解读——无论是 AER 实证文章、QJE 理论文章、Econometrica 结构估计，还是中文 CSSCI 政策论文。

## 技能结构

这是一个**技能集合**——一个主协调技能，搭配**八个**专项子技能和四个参考文件。

```
econ-paper-reader/
├── SKILL.md                               ← 主技能：分类 → 路由 → 产出阅读报告
├── README.md                              ← 英文说明
├── README_CN.md                           ← 中文说明（本文件）
│
├── subskills/
│   ├── epr-structure/SKILL.md             ← 论文结构解析（各部分期望内容）
│   ├── epr-empirical/SKILL.md             ← 实证文献（RF回归 + 结构估计）
│   ├── epr-theory/SKILL.md                ← 理论模型（假设、命题、推论）
│   ├── epr-methodology/SKILL.md           ← 计量方法论文（新估计量、识别策略辨析）
│   ├── epr-causal-inference/SKILL.md      ← 因果识别策略（DiD/IV/RDD/SC等）
│   ├── epr-tables-figures/SKILL.md        ← 表格与图形解读
│   ├── epr-policy-context/SKILL.md        ← 政策与制度背景提取
│   └── epr-related-refs/SKILL.md          ← 延伸阅读文献选取与格式化
│
└── references/
    ├── paper-taxonomy.md                  ← 文献类型分类体系
    ├── causal-methods-ref.md              ← 因果推断方法深度参考
    ├── theory-components-ref.md           ← 理论模型构件速查
    └── chinese-vs-english.md             ← 中英文文献规范差异
```

子技能路由**按文章类型确定性触发**——分类完成后，精确加载对应子技能，不多加载，不猜测。

## 技能能做什么

| 任务 | 调用子技能 |
|------|-----------|
| 判断文章类型（实证/理论/结构/计量方法） | `epr-structure` + `paper-taxonomy.md` |
| 产出完整结构化阅读报告 | 所有相关子技能 |
| 叙事式开篇：这篇文章讲了个什么故事 | 主技能 SKILL.md |
| 提取政策背景与制度信息 | `epr-policy-context` |
| 呈现回归方程/模型方程及变量说明 | `epr-empirical` / `epr-theory` |
| 评估识别策略的可信度 | `epr-causal-inference` + `causal-methods-ref.md` |
| 读懂回归表格 | `epr-tables-figures` |
| 解码理论模型的假设和命题 | `epr-theory` + `theory-components-ref.md` |
| 读懂计量方法创新类文章 | `epr-methodology` |
| 审稿人视角的全面评审 | 所有子技能 |
| 阅读中文经济学文献 | `epr-policy-context` + `chinese-vs-english.md` |
| 推荐延伸阅读文献 | `epr-related-refs` |

## 使用方式

### 在 Claude Code / AWS Kiro 中使用

将本目录放入 `.claude/skills/` 文件夹（或技能加载器指向的路径），随后直接提问：

> "帮我读一下这篇文献，识别策略可信吗？"  
> "总结这篇工作论文的主要结论。"  
> "帮我理解第三节的模型。"  
> "表2说明了什么？"

技能会在涉及经济学文献阅读的任务时自动触发。

### 对 PDF 文献的支持

本技能依赖 PDF 阅读能力。建议搭配 PDF 阅读工具。

### 阅读深度

**快速扫读**：摘要 + 引言 + 结论 + 浏览表格。

**标准阅读**：全文阅读，产出完整结构化报告。

**审稿级阅读**：逐节批判性评估，适合判断发表潜力。

## Token 消耗说明

这是一个**重量级技能**——全面的分析需要加载多个子技能文件并完整阅读文献。使用前请对消耗量有所预期：

| 文献长度 | 大致 token 消耗 |
|---|---|
| 短篇工作论文（~20–30 页） | ~150k–200k tokens |
| 完整期刊论文（~40–50 页） | ~200k–300k tokens |

以上数据基于 Opus 级别模型进行标准阅读。快速扫读模式消耗显著更少。

## 阅读报告格式

```
# [论文标题]

作者 / 来源 / 研究领域 / Paper type

──────────────────────────────────

这篇文章讲了个什么故事
  叙事式开篇：背景、空白、方法、发现、意义

政策与背景  [实证类/中文文献]
  政策/事件表 + 政治制度背景

核心问题
  一句话研究问题

研究设计
  识别策略或理论框架

模型设定  [理论/结构估计文章]
  LaTeX 核心方程 + 符号说明表 + ⚠️ 关键假设

实证设计  [RF 实证文章]
  LaTeX 估计方程 + 变量说明表 + ⚠️ 设计注意事项

主要发现
  含经济量级的核心结论

核心贡献
  创新点 vs 既有文献

亮点
  最有说服力之处

不足与疑问
  识别威胁、模型缺陷、遗漏稳健性检验

综合评价
  总体判断与发表价值

延伸阅读
  从参考文献列表中选取的关键延伸阅读（ref-format 格式）
```

## 设计理念

本技能的核心洞察：**阅读与写作互为逆过程**。顶级期刊写作遵循严格规范——每个部分有期望内容，每种识别策略有必要诊断，每篇理论文章有标准构件。通过编码这些写作规范，技能知道阅读时应该寻找什么。
